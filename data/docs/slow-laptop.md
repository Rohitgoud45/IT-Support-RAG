# Laptop running slowly

Start by restarting your laptop. Restart at least once a week, because sleep and hibernate do not clear memory fully.

Check free disk space in File Explorer. Keep at least 15 percent of the drive free. Run "Disk Cleanup" from Software Center if you are below that.

Open Task Manager, go to the Startup tab, and disable apps you do not need at login. Install pending Windows updates.

If memory use stays above 90 percent during normal work, open a ticket so we can assess a RAM upgrade. Laptops older than 4 years are eligible for a hardware refresh.
