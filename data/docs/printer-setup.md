# Printer setup and print problems

To add a printer, open Software Center and install the driver package named "Office Print Drivers". Then open Settings, Printers and scanners, choose Add device, and enter the path \\printserver\ followed by the printer name.

The shared printer on the third floor is named PRN-3F-01. The second floor printer is PRN-2F-01.

If documents are stuck in the queue, open the Services app, restart the Print Spooler service, then delete the stuck jobs from the printer queue and print again.

If the printer panel shows error E-12, there is a paper jam in the rear tray. Open the rear door, remove the paper gently, and close the door.
