# Wi-Fi connection

Company laptops connect to the Corp-Secure network, which authenticates with a device certificate and does not ask for a password. Visitors use Corp-Guest. The Corp-Guest password changes every week and is posted at the reception desk.

If you see a certificate error on Corp-Secure, open Software Center and run "Enroll device certificate", then disconnect and reconnect to the network.

If Wi-Fi is slow or drops, forget the network, reconnect, and prefer the 5 GHz band, which is less crowded than 2.4 GHz.
