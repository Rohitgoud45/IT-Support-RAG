# Installing software

Approved software is installed from Software Center without admin rights. Open Software Center, search for the app, and click Install.

If the app you need is not in Software Center, submit a "Software request" in the service portal. Your manager approves the request, and Security reviews any new vendor. Most requests are completed within 3 business days.

Local admin rights are not given for installing software. Developers who need them can request a time-limited admin account through the "Privileged access" form; it expires after 8 hours.

Do not install browser extensions that are not on the approved list. Unapproved extensions are removed automatically every night.
